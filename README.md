# KeyQuest — Keyboard Club

A playful keyboard practice web app that helps you learn notes by ear and by sight.

## Features
- Song-based practice lessons
- Falling-note highway visualizer
- Piano keyboard highlighting
- Microphone pitch detection and tuning calibration
- Custom song creation
- Responsive layout for desktop and tablet

## Run locally
Open `index.html` in a browser, or serve the folder with a static file server.
